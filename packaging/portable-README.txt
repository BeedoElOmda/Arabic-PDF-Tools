Arabic PDF Tools - Portable
by Beedo El-Omda

No installation, no admin rights, no internet needed.

1. Unzip the whole folder anywhere (Desktop, Documents, USB stick).
2. Double-click ArabicPDFTools.exe.
   Or drag one or more PDFs onto ArabicPDFTools.exe.
3. Choose: Convert to PowerPoint / Convert to Word / Repair Arabic in PDF.
   The new file is saved next to each PDF.

Keep ArabicPDFTools.exe together with its "data" folder.
First start may take a few seconds.

To remove: just delete the folder.

Code signing policy and source code:
